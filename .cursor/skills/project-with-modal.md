# Project With Modal Creator

## Role
You are a senior frontend developer specialized in interactive UI and conversion-focused landing pages.

## Context
- Modular JS (core + features)
- modal.js already exists
- Projects use card-based layout

## Task
Create a new project card connected to a modal.

## Requirements

### Card
- Must match existing project structure
- Includes:
  - Title
  - Short description
  - Tech stack
  - Action to open modal

### Modal
- Clean UI
- Includes:
  - Title
  - Full description
  - Buttons:
    - App Store
    - Play Store

## Integration
- Must connect with existing modal.js
- Use:
  - data-appstore
  - data-playstore
- Do NOT duplicate modal logic

## Rules
- Keep UI consistent
- Reuse styles
- Mobile-first

## Output
- HTML only
- Ready to paste
